# GooseOverlay

Нативный плагин для 32- и 64-битных версий TeamSpeak 3, который показывает участников текущего голосового канала и подсвечивает говорящего поверх **Battles for Glory**.

Оверлей реализован отдельным прозрачным окном без внедрения кода в процесс игры. Поэтому игра должна работать в **оконном** или **безрамочном оконном** режиме. В эксклюзивном полноэкранном режиме Windows не может гарантировать показ такого окна поверх DirectX.

## Возможности

- список пользователей текущего канала TeamSpeak;
- зелёный индикатор активной речи, жёлтый — whisper;
- входящие whisper из других каналов: говорящий появляется сверху с пометкой `[WHISPER]` на время передачи;
- большой аватар лидера под списком только во время речи; показ можно полностью отключить в настройках;
- красный значок перечёркнутого микрофона у пользователей с выключенным микрофоном;
- значок перечёркнутого динамика у пользователей с отключённым входящим звуком;
- автоматический поиск окна Battles for Glory;
- скрытие, когда игра неактивна;
- клики и ввод проходят сквозь оверлей;
- настройка положения, размера, прозрачности и имён процессов через INI;
- перемещение панели мышью с автоматическим сохранением позиции;
- сброс только координат панели к значениям по умолчанию;
- встроенное окно настроек в интерфейсе дополнений TeamSpeak;
- команда и горячая клавиша для быстрого отключения.

## Сборка

Требуется Windows 10/11 и Visual Studio 2022 Build Tools с компонентом **Desktop development with C++**.

Клонируйте репозиторий вместе с официальным TeamSpeak SDK:

```powershell
git clone --recursive https://github.com/artesk/GooseOverlay.git
cd GooseOverlay
```

```powershell
.\build.ps1
```

После сборки `./test.ps1` проверяет события whisper, сохранение Unicode-ника, ресурсы портрета, часы (настройки, часовые пояса, сезонный перевод времени) и отрисовку кадров для x86/x64. Примеры панели сохраняются в `dist/leader-preview.png` и `dist/clock-preview.png`.

Скрипт создаёт:

- `dist\package\plugins\bfg_overlay_win32.dll`;
- `dist\package\plugins\bfg_overlay_win64.dll`;
- `dist\GooseOverlay.ts3_plugin` — установочный пакет TeamSpeak.

Также проект можно собрать CMake, если он установлен:

```powershell
cmake -S . -B build-win64 -A x64
cmake --build build-win64 --config Release
cmake -S . -B build-win32 -A Win32
cmake --build build-win32 --config Release
```

## Установка и запуск

1. Дважды щёлкните `dist\GooseOverlay.ts3_plugin` и подтвердите установку.
2. Перезапустите TeamSpeak 3 и проверьте, что **GooseOverlay** включён в `Tools → Options → Addons`.
3. Подключитесь к голосовому каналу.
4. Запустите Battles for Glory в безрамочном или оконном режиме.

Команда `/goose status` в чате TeamSpeak покажет, найдено ли окно игры.

## Команды

```text
/goose toggle
/goose show
/goose hide
/goose move
/goose opacity 40..255
/goose reload
/goose status
```

В настройках горячих клавиш TeamSpeak доступны действия `Toggle GooseOverlay` и `Move GooseOverlay with mouse`. Назначьте им удобные сочетания клавиш.

## Настройка

Часы в заголовке включены по умолчанию и показывают московское время в формате **ЧЧ:ММ:СС**. В настройках можно снять галочку **Показывать время в заголовке** или выбрать другой часовой пояс из списка Windows, включая **Время компьютера**. Изменения применяются без перезапуска. Сезонный перевод времени учитывается по системным правилам выбранного пояса. В INI: `clock_enabled=1` и `clock_timezone=Russian Standard Time`; пустой `clock_timezone=` означает время компьютера. Системное время и часовой пояс Windows плагин не меняет.

Поле **Ник клан-лидера** задаёт, кому показывать портрет; по умолчанию — «восток». Изменение применяется кнопкой **Применить** и сохраняется после перезапуска. Сравнение ника точное, без учёта регистра и пробелов по краям. Кадры встроены в DLL; переносить картинки отдельно не нужно.

По умолчанию аватар размером **128 × 128 px** располагается под списком, по центру панели, только когда лидер говорит в текущем канале или передаёт входящий whisper. В тишине и при выключенном микрофоне аватар скрыт; во время речи кадры анимируются. Размер аватара настраивается от 64 до 256 px, при нехватке места в окне игры он уменьшается. Чтобы полностью отключить показ, снимите галочку **Показывать аватар под оверлеем во время речи лидера**. В INI это `leader_enabled=1` и `leader_size=128` в секции `overlay`. Вариант рядом с ником удалён; старый параметр `leader_inline` игнорируется.

Анимация следует статусу речи TS3, а не громкости звука. В INI ник хранится в `overlay.leader_name`; Unicode-символы записываются как `\uXXXX`, чтобы не зависеть от языка Windows.

Нажмите **Настроить** у `GooseOverlay` в списке дополнений TeamSpeak. В окне можно изменить положение панели, прозрачность, ширину, размер шрифта, высоту строк, число отображаемых пользователей и параметры поиска игры. Кнопка **Применить** обновляет оверлей без перезапуска.

Настройки сохраняются в пользовательском каталоге конфигурации TeamSpeak (`%APPDATA%\TS3Client\goose_overlay.ini` при стандартной установке), поэтому для их изменения не нужны права администратора. При обновлении параметры из старого `bfg_overlay.ini` переносятся автоматически.

### Перемещение мышью и сброс положения

Нажмите **Ctrl+Alt+M** прямо в игре: сочетание работает сразу, назначать его в TeamSpeak не нужно. Оно действует только при включённом оверлее и активном окне игры; удержание клавиш не вызывает повторных переключений. Заголовок сменится на **Тяните мышью**. Зажмите левую кнопку на панели и перенесите её. При отпускании мыши координаты сохраняются автоматически, режим перемещения завершается, и клики снова проходят в игру. Открытые настройки также получают новые координаты.

Внизу панели постоянно видна подсказка **Ctrl+Alt+M / Переместить панель**. В режиме перемещения она показывает **Отпустите ЛКМ — сохранить** и **Esc / ПКМ — отмена**. Размер панели при переключении подсказок не меняется. Кнопка **Переместить мышью**, назначаемое действие TeamSpeak `Move GooseOverlay with mouse` и команда `/goose move` также доступны.

**Escape** в активном окне игры, правый клик по панели или повторное включение горячей клавиши отменяют перенос. Потеря фокуса во время перетаскивания тоже возвращает прежнюю позицию. Панель ограничена краями окна игры; при уменьшении окна остаётся доступной. Режим перемещения не сохраняется после перезапуска.

Кнопка **Сбросить положение** возвращает только поля **Отступ справа** и **Отступ сверху** к **24** и **72 px**. Для применения нажмите **Применить** или **Сохранить**; **Отмена** позволяет отказаться от сброса. Ширина, прозрачность, шрифт, аватар, часы и остальные настройки этой кнопкой не изменяются.

Если `/goose status` сообщает `waiting for game`, добавьте фактическое имя EXE игры в `processes` либо исправьте `title_contains`, затем выполните `/goose reload`.

```ini
[game]
processes=BattlesForGlory.exe,Battles For Glory.exe,BFG.exe
title_contains=Battles for Glory
hide_when_unfocused=1

[overlay]
enabled=1
opacity=225
width=310
offset_x=24
offset_y=72
row_height=30
font_size=17
max_clients=16
```

## Ограничения

«Глобальная» речь отображается, если ваш клиент получает её как whisper. Плагин не видит обычные разговоры в чужих каналах и не может определить полный список получателей whisper (все каналы, группа или личное обращение).

- Только TeamSpeak 3 Client API 26 и Windows; поддерживаются клиенты x86 и x64.
- Эксклюзивный fullscreen не поддерживается; используйте borderless/windowed.
- Плагин не читает память игры и не внедряется в неё. Это сделано намеренно для совместимости и снижения риска конфликтов с античитом.

SDK загружен из официального репозитория [TeamSpeak Client Plugin SDK](https://github.com/teamspeak/ts3client-pluginsdk). Требования игры указывают Windows 10 x64 и DirectX 11: [Steam — Battles for Glory](https://store.steampowered.com/app/3646700/Battles_For_Glory/?l=russian).
